# Contributing

Thank you for wanting to fix something. Please read the first paragraph before
you open a pull request, it will save you the work.

## This repository is generated

Every file except this one, `LICENSE` and the templates in `.github/` is
rebuilt from scratch every Monday from [Brick Passport](https://brickstorestamps.com),
which is where the store data actually lives. A pull request editing
`data/stores.json` or a page under `stores/` is overwritten by the next run, so
we cannot merge it even when it is right.

## What to do instead

Open an issue. There are three forms, and they ask for exactly what is needed
to change the record at the source:

* **New store** for a shop that is missing from the list
* **Store closed** for one that has shut down
* **Correction** for a wrong address, name, phone number or position

You do not need an account on the site to report something here.

## What makes a report easy to act on

A link to something public: the store page on lego.com, an operator's site, a
mall directory, a news article, a dated photo of the storefront. Not because we
distrust you, but because a store list without sources rots quietly and nobody
notices until someone stands in front of a wall.

For a closure, the year matters. For a new store, the opening date if you know
it. For coordinates, a map link is easier for everyone than typing numbers.

## Local-script names

Many stores outside Europe carry a name in the local script, and roughly half
of the Chinese entries still have none. If you can supply one, that is one of
the most useful things you can add here.

## Languages

English or German, whichever is easier for you. The files themselves are
English so that everyone can read them.
